# Task 4 — PulsePlay 5-Star Music Player

## Included
- `index.html`
- `style.css`
- `script.js`

## Features
- Responsive music-player UI
- 6 demo tracks using public SoundHelix MP3 sources
- Play / pause
- Previous / next
- Shuffle
- Repeat
- Seek/progress bar
- Volume control
- Search
- Favorites saved with localStorage
- Favorites / Queue / Focus / Chill / Energy views
- Dark / light theme saved with localStorage
- Mobile sidebar
- Keyboard controls:
  - Space = play/pause
  - Left/Right = seek
  - Up/Down = volume
  - M = mute
- Error feedback if an online audio source cannot load
- Reduced-motion support

## Run
Use VS Code Live Server and open `index.html`.
Internet is required for the demo MP3 files because they are loaded from public URLs.

## Submission
You can replace the demo tracks in `script.js` with your own MP3 URLs or local audio files if your assignment requires personal songs.
